# data-agent-daily

每日 Data Agent 热点简报，自动同步并通过 GitHub Pages 发布：

- 仓库：https://github.com/DataXAgent/data-agent-daily
- 站点：https://dataxagent.github.io/data-agent-daily/
- 每期一篇 Markdown：`YYYY-MM-DD.md`，并在 `index.md` 归档里加一行
- 内容来源：新闻网站、社交媒体（X / Instagram / Facebook / LinkedIn / Reddit 等）、公司官方网站与博客
- 每期结构：概括 + 原文链接，并标注来源日期与可信度提示
